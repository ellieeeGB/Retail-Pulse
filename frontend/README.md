# Retail Pulse Frontend

Aplicacion React + Vite + Tailwind para Retail Pulse.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

Por defecto consume la API desde `VITE_API_URL`. Si no existe, usa `/api/v1`.

En desarrollo local, `vite.config.ts` incluye proxy de `/api` a `http://localhost:8000`.
